Rappel théorique
1 Équations du second degré
Δ = b² − 4ac
x = −b ± √Δ2a
Δ > 0 deux solutions x₁ et x₂
Δ = 0 une solution : x = −b2a
Δ < 0 pas de solution réelle
2 Tableau de signes
Degré 1 : ax + b (racine x₀ = −b⁄a)
signe contraire de a│0│signe de a
Degré 2 : ax² + bx + c
1. Résoudre l'équation ax² + bx + c = 0
2. Signe de a partout, sauf entre les 2 racines (si elles existent)
Δ > 0 deux racines x₁ et x₂
Δ = 0 une racine x₁ → signe de a partout, sauf 0 en x₁
Δ < 0 pas de racine → signe de a partout
3 Factorisation
Degré 2 : ax² + bx + c
1. Résoudre l'équation ax² + bx + c = 0
2. On utilise la formule : a(x − x₁)(x − x₂)
Δ = 0 a(x − x₁)²
Δ < 0 pas de factorisation possible
